# جواب — سیستم پاسخ خودکار با هوش مصنوعی

پنل ساده با PHP خالص و معماری MVC (بدون Composer و فریم‌ورک) که پرسش و پاسخ‌های ثبت‌شده در دیتابیس MySQL را به‌عنوان **دانشنامه** استفاده می‌کند و سوال کاربران را با کمک هوش مصنوعی و فقط بر اساس همین دانشنامه جواب می‌دهد. سیستم رایگان است و احراز هویت ندارد.

## امکانات
- **دانشنامه** (`/knowledge`): ثبت، ویرایش، جستجو و حذف پرسش و پاسخ.
- **قوانین ثابت** (دکمه‌ی «قوانین ثابت» در صفحه‌ی دانشنامه، پاپ‌آپ): قانون‌هایی مثل «پاسخ همیشه با لحنی محترمانه اما صمیمی باشد» که روی همه‌ی پاسخ‌ها اعمال می‌شوند. هر ردیف یک قانون است و قابل ویرایش، حذف و فعال/غیرفعال کردن است. وقتی قانون فعالی هست، حتی تطابق‌های کامل هم از AI عبور می‌کنند تا قوانین اعمال شوند (اگر AI در دسترس نباشد، همان پاسخ دانشنامه داده می‌شود).
- **تحلیل دانشنامه‌ها** (`/analysis`):
  - **آمار استفاده**: نمودار دانشنامه‌ها به ترتیب تعداد سؤال‌هایی که با آن‌ها پاسخ داده شده، با عدد دقیق.
  - **دانشنامه‌های مشکل‌دار**: با دکمه‌ی «شروع تحلیل»، هوش مصنوعی محتوا را از نظر معنایی بررسی می‌کند و موارد چندمعنایی، مبهم، متناقض یا هم‌پوشان را با نوع مشکل، علت، دانشنامه‌ی مرتبط و متن دقیق مشکل‌دار نشان می‌دهد. هشداری که متن ذکرشده‌اش عیناً در دانشنامه نباشد، یا اطمینان مدل کمتر از ۸۰ باشد، دور ریخته می‌شود. تحلیل مرحله‌به‌مرحله و با رعایت ریت لیمیت AI اجرا می‌شود.
  - **استثناها**: دکمه‌ی «استثنا» هشدار یک دانشنامه را از لیست فعال به لیست استثناها می‌برد (در دیتابیس ذخیره می‌شود؛ محتوا تغییر نمی‌کند) و «خروج از استثنا» آن را برمی‌گرداند.
- **گفتگو** (`/`): صفحه‌ی چت شبیه ChatGPT؛ گفتگوهای اخیر در سایدبار (ذخیره در مرورگر).
- **آستانه‌ی دقت**: پاسخ فقط وقتی ارسال می‌شود که اطمینان حداقل `MIN_CONFIDENCE` (پیش‌فرض ۸۰٪) باشد؛ در غیر این صورت پیام «پاسخ دقیقی پیدا نشد» نمایش داده و سوال در **سوال‌های بی‌پاسخ** (`/unanswered`) ثبت می‌شود تا با یک کلیک به دانشنامه اضافه شود.
- **ریت لیمیت مدل AI**: سقف درخواست در دقیقه و روز برای کل سیستم، سقف درخواست هم‌زمان، احترام به `429` و `Retry-After` (توقف موقت ارسال)، و سقف سوال برای هر کاربر (IP).
- **صرفه‌جویی در سهمیه‌ی AI**: سوالی که تقریباً عین یک سوال دانشنامه باشد بدون AI جواب داده می‌شود؛ پاسخ‌ها کش می‌شوند (با هر تغییر دانشنامه کش باطل می‌شود)؛ وقتی دانشنامه بزرگ است فقط نزدیک‌ترین موارد برای AI فرستاده می‌شود.

## نصب
1. PHP 7.4+ (پیشنهادی 8.2) با افزونه‌های `pdo_mysql`، `mbstring`، `curl` و MySQL 5.7+ یا MariaDB 10.3+.
2. فایل `.env.example` را به `.env` کپی و اطلاعات دیتابیس (`DB_*`) و یک `APP_KEY` تصادفی را وارد کنید.
3. روت سایت را روی پوشه‌ی `public` بگذارید (یا روی ریشه‌ی پروژه؛ `index.php` و `.htaccess` ریشه هم کار می‌کنند).
4. هوش مصنوعی پیش‌فرض **Agnes AI** است (`AI_URL=https://apihub.agnes-ai.com/v1/chat/completions`، `AI_MODEL=agnes-2.5-flash`): در [پلتفرم Agnes](https://platform.agnes-ai.com/) حساب بسازید، یک API Key بگیرید و در `AI_API_KEY` بگذارید (به‌صورت `Authorization: Bearer` ارسال می‌شود). هر سرویس دیگر سازگار با OpenAI هم با تغییر همین سه مقدار کار می‌کند.
5. صفحه‌ی اصلی را باز کنید: **دیتابیس (اگر نباشد) و همه‌ی جدول‌ها خودکار ساخته می‌شوند** (`database/migrations/*.sql`).

سرور توسعه:

```bash
php -S 127.0.0.1:8080 -t public router.php
```

## ساختار
```
app/Core         هسته: App، Router، Request، Response، View، Database، Migrator، Env، Csrf، Session
app/Controllers  ChatController، KnowledgeController، RuleController، AnalysisController، UnansweredController
app/Models       Knowledge، Rule، KbIssue، ChatMessage، Unanswered، Setting
app/Services     AnswerService (فلوی اصلی)، KbAnalyzer (تحلیل دانشنامه)، AiClient، Retriever، RateLimiter، TextNormalizer
app/Views        قالب‌ها (layouts/main.php = سایدبار + محتوا)
config           app.php (تنظیمات از .env)، routes.php
database         migrations
public           index.php و assets (css/js)
storage          لاگ‌ها و کش
```

## فلوی پاسخ
1. ریت لیمیت کاربر
2. پیدا کردن نزدیک‌ترین پرسش و پاسخ‌ها (نرمال‌سازی فارسی، کلمات مشترک، سه‌حرفی‌ها، تحمل غلط تایپی)
3. تطابق تقریباً کامل (`KB_DIRECT_MATCH`) ← پاسخ مستقیم بدون AI
4. کش پاسخ
5. ریت لیمیت و هم‌زمانی مدل ← درخواست به AI با بدنه‌ی `model / messages[system,user] / temperature / top_p / stream:false / max_tokens`
6. قوانین ثابتِ فعال به پیام سیستمی مدل اضافه می‌شوند.
7. مدل خروجی `{"answer","confidence","sources"}` می‌دهد؛ اگر `confidence` کمتر از `MIN_CONFIDENCE` بود یا منبع معتبری نداشت، پاسخ ارسال نمی‌شود.

همه‌ی تنظیمات در `.env.example` توضیح داده شده‌اند.

## لاگ‌ها
- `storage/logs/app-YYYY-MM-DD.log`: لاگ عمومی برنامه (خلاصه‌ی هر درخواست AI، خطاهای دیتابیس و ...).
- `storage/logs/http-ai.log`: هر بار که درخواست به AI خطا بگیرد (خطای شبکه، کد HTTP غیر از 200، 429، یا پاسخی که JSON معتبر ندارد)، **JSON کامل درخواست و JSON کامل پاسخ** همراه با هدرها، کد HTTP و زمان در این فایل نوشته می‌شود. کلید API در لاگ ماسک می‌شود. اگر حجم فایل از ۲۰ مگابایت بیشتر شود، با نام `http-ai-تاریخ.log` بایگانی و فایل تازه ساخته می‌شود.
